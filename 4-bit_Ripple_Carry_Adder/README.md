# 4-bit Ripple Carry Adder using Verilog HDL

## Overview

This project implements a 4-bit Ripple Carry Adder using four Full Adders connected in series.

## Features

- 4-bit Addition
- Carry propagation
- Modular design using Full Adder
- Verilog HDL implementation
