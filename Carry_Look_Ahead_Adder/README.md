# 4-bit Carry Look-Ahead Adder using Verilog HDL

## Overview

This project implements a 4-bit Carry Look-Ahead Adder (CLA) using Verilog HDL. Unlike the Ripple Carry Adder, the CLA computes carry signals in parallel, reducing propagation delay and improving addition speed.

## Features

- 4-bit Binary Addition
- Parallel Carry Generation
- Reduced Carry Propagation Delay
- Verilog HDL Implementation
- Functional Simulation
- RTL Schematic
